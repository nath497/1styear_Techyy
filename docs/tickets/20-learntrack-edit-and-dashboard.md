# 20 — LearnTrack: edit, delete, filter and the dashboard card

**What to build:** a learner can edit a topic (name, subject, status,
note), delete one after an "are you sure?", and filter LearnTrack by
status. Their dashboard gets a LearnTrack card showing how many topics
are at Need to Review and up to 3 of them, once they have topics.
